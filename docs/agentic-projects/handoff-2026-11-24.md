### Where things live now

- **Data sources:** `providers/yahoo/` and `providers/alpaca/`. `__init__.py` holds the declaration and `implementation.py` holds the code. The old `data/provider/{alpaca_provider,yfinance_provider,symbol_details,symbol_search}.py` files are gone.
- **Framework:** `data/provider/spec.py` (declarations), `registry.py` (discovery, sealing, credential lookup), `routing.py` (`CapabilityRouter`), `base.py` (`DataProvider`; unimplemented methods raise `UnsupportedCapabilityError`).
- **Startup:** `simplechart/bootstrap.py`, called from `main.py`. Order: output safety → discover and seal providers → load extension plugins → window.
- **Agent guide for new sources:** `docs/skills/data-provider.md`, linked from `AGENTS.md`, with forwarders in each agent's skills folder.
- **Fallback:** `FALLBACK_PROVIDER = "yfinance"` is the only source name allowed outside `providers/`. `test_application_has_no_provider_imports_or_literals` enforces this.

### Visible changes the user approved

1. Switching providers reloads Symbol Details, earnings and the company name from the new source.
2. Compare Bars adds a "SIP (15-minute delayed)" row when the chart uses Alpaca's real-time SIP feed.
3. When saving connection settings fails, what the user typed stays in the dialog.

### Rule decided during the build

Error messages written by a provider must be a fixed sentence. The only thing they may insert is the provider's own display name. This keeps outside text, such as library errors, off the screen while keeping Alpaca's useful advice. `test_provider_error_rule_rejects_unsafe_source` enforces it.
